### Sobre o Projeto
Uma ferramenta de interface minimalista projetada para lidar com redes de Classe A, B e C. O sistema aceita a entrada de máscaras tanto em formato Decimal quanto em notação CIDR, realizando cálculos matemáticos nos bastidores para validação de bits contínuos e entrega instantânea de resultados.

### Funcionalidades Principais
* Validação estrita de endereços IPv4 e limites de octetos.
* Verificação matemática de continuidade de bits para máscaras de sub-rede.
* Suporte nativo para máscaras CIDR (ex: 24) e Decimais (ex: 255.255.255.0).
* Cálculo de Endereço de Rede, Broadcast, Tamanho do Bloco e Faixa de IPs Úteis.
* Prevenção de erros do usuário em tempo real.

### Tecnologias Utilizadas
* HTML5
* Tailwind CSS 
* JavaScript
